# Simbi Time Clock

Gostaria de criar um sistema de ponto simples, a empresa entra na conta, cadastra a empresa, cadastra o funcionarios atribui login e senha para eles e em outra pagina eles podem registrar os horarios e saber quantas horas extras tem. O sistema se chama simbi, conecte no suba base e por favor não gaste mais de 5 créditos Lovable nesse MVP
